# 🚀 Meu Portfólio Profissional

## 📋 Visão Geral do Projeto
Este projeto consiste em um portfólio web responsivo e moderno, desenvolvido para centralizar e apresentar meus projetos de desenvolvimento, cursos realizados, eventos acadêmicos/profissionais e certificados conquistados. O objetivo é criar um espaço visualmente atraente para destacar minha trajetória e habilidades na área de tecnologia.

---

## 🔗 Link da Aplicação
Acesse a aplicação em funcionamento: portifoliomiguel-cinco.vercel.app

---

## 🛠️ Tecnologias e Bibliotecas Utilizadas
As seguintes tecnologias e ferramentas foram utilizadas na construção do projeto:
* **HTML5**: Estruturação semântica das páginas web.
* **CSS3**: Estilização visual, layout responsivo e efeitos visuais (`Potif lio/css/style.css`).
* **JavaScript**: Interatividade e dinamismo nas páginas (quando aplicável).
* **Vercel**: Plataforma de hospedagem e deploy contínuo.
